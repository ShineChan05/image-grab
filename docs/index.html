为什么需要它

告别手动一张张右键保存

电商详情页的商品图分散在页面各个角落，往往还混合着图标、Logo 与占位图。图提取帮你自动完成「扫描 → 过滤 → 预览 → 勾选 → 下载」全流程，让收集素材变得像复制粘贴一样简单。

图片分散，难以收集

详情页的主图、细节图、实拍图散落在不同区块，逐张另存为效率极低。

无法批量保存

浏览器原生只能逐张保存，遇到几十张图时，重复操作既繁琐又容易遗漏。

格式不统一

WebP、JPG、GIF 混在一起，命名杂乱。图提取统一转为 PNG 并按序编号。

核心功能

六个能力，覆盖提取全流程

从扫描到落盘，每一步都为「快」和「准」设计。

一键提取

自动扫描页面所有商品图，兼容懒加载与滚动加载的图片。

智能过滤

自动排除图标、Logo、占位图等无关图片，只保留真正的商品图。

集中预览

新页面网格展示所有提取结果，缩略图、尺寸、序号一目了然。

自由勾选

全选 / 反选 / 按需勾选，想下载哪张就下载哪张。

统一 PNG

自动将图片统一转为 PNG 格式，命名规范、可直接用于排版设计。

批量下载

一键保存到本地，文件名自动按 商品图_001.png 顺序编号。

安装步骤

四步装好，马上开用

无需登录商店，开发者模式加载本地文件夹即可。

  1. 1

    下载插件压缩包并解压

    下载 image-grab.zip，解压到本地文件夹（如 D:\image-grab），保持目录结构完整。

  2. 2

    打开扩展管理页

    打开 Chrome，地址栏输入 chrome://extensions 后回车。

  3. 3

    开启「开发者模式」

    打开页面右上角的 开发者模式 开关。

  4. 4

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择第 1 步解压出的文件夹即可完成安装。
