# 电商图片提取下载助手

一个 Chrome 扩展，用于在**淘宝 / 天猫、京东、拼多多（含商家版）**的商品详情页一键提取商品图片，并在新页面中集中展示、勾选、批量下载为 PNG。

## 文件结构

```
image-grab/
├── manifest.json   # MV3 清单：权限、后台、内容脚本声明
├── content.js      # 注入悬浮按钮 + 提取图片逻辑
├── content.css     # 悬浮按钮样式
├── background.js   # Service Worker：消息转发 + 下载/转 PNG
├── gallery.html    # 提取结果展示页
├── gallery.css     # 展示页样式
└── gallery.js      # 展示页交互与批量下载
```

## 安装步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
2. 打开右上角「开发者模式」开关。
3. 点击左上角「加载已解压的扩展程序」，选择本项目文件夹 `image-grab`。
4. 安装完成后，扩展列表中会出现「电商图片提取下载助手」。

## 使用说明

1. 打开淘宝 / 天猫、京东、拼多多（含商家版）的**商品详情页**。
2. 页面右下角会出现橙红色的「获取图片」悬浮按钮（非详情页不会显示）。
3. 点击按钮，等待提取完成（会弹出数量提示），自动打开「商品图片」新页。
4. 在展示页中：
   - 每张图片显示缩略图、尺寸与序号；
   - 点击卡片或复选框可勾选，顶部支持「全选 / 反选」；
   - 点击「下载选中」开始批量下载，页面会显示进度与结果。
5. 图片会以 `商品图_001.png`、`商品图_002.png` … 命名，保存到浏览器默认下载目录。

## 注意事项

- 图片统一转 PNG 通过扩展页 `gallery.js` 中的 `fetch + createImageBitmap + OffscreenCanvas` 完成（扩展页拥有 host_permissions，可跨域读取图片）；若个别图片来自未覆盖的 CDN，会自动回退为原格式下载。
- 扩展无图标不影响使用（Chrome 会显示默认图标）；如需图标，在 `manifest.json` 增加 `"icons"` 字段并放置对应 PNG 即可。
- 若某平台的商品详情页 URL 形态变化导致按钮未显示，可调整 `content.js` 中 `isProductDetailPage()` 的判断规则。
